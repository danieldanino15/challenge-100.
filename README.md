# אתגר 100 ימים

100 שכיבות סמיכה + 100 כפיפות בטן ביום, 100 ימים, החל מ-23.11.2026.

## מבנה
- `index.html` – הדף עצמו.
- `api/state.js` – מחזיר את כל המשתתפים והרישומים.
- `api/log.js` – שמירת יום (דורש קוד אישי של 4 ספרות).
- `api/join.js` – הצטרפות משתתף חדש.
- `lib/store.js` – חיבור ל-Upstash Redis.

## הגדרה בוורסל
1. Storage → Upstash Redis → לחבר לפרויקט (משתני הסביבה נוספים לבד).
2. אופציונלי: `ADMIN_PIN` – קוד מנהל שמאפשר לתקן כל שורה.
3. אופציונלי: `PIN_SALT` – מחרוזת אקראית לגיבוב הקודים.

כל משתתף קיים בוחר קוד אישי בפעם הראשונה שהוא שומר. מאז רק מי שיודע את הקוד יכול לעדכן את השורה שלו.
